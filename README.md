# my-first-project

A simple weather app with an Apple-style glassmorphic design, powered by the free [Open-Meteo](https://open-meteo.com/) API (no API key needed). The default location is Hobe Sound, Florida, and you can search for any city.

## Files

- `index.html`: page structure
- `style.css`: glassmorphic styling
- `app.js`: fetches and renders the weather

## Run locally

Open `index.html` in a browser.

## Deploy to Netlify

There is no build step. Drag this folder into Netlify, or connect the repo with the build command left blank and the publish directory set to the repository root.
